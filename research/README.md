# Research archive

`notebooks/` preserves the original exploratory notebooks and their outputs,
including interpolation studies, large animations, historical experiment runs,
and earlier embedding attempts. They are research records, **not maintained
API demonstrations**. Some depend on external datasets, optional packages,
old wildcard imports, or historical task layouts; do not use them as correctness
references for version 0.2.

The actively maintained, executed demonstrations are in [`../notebooks`](../notebooks/README.md).
In particular, `EmbeddingTest.ipynb` there replaces the old faulty embedding
experiment, `TestingMixedSE.ipynb` documents the mixed-state convention, and
`Tutorial.ipynb` walks through all four supported experimental workflows.
No original research output has been discarded. The repository's separate
`qbist_bell_inequalities/` and `triple_products_notes/` remain research material.

`readme_0_1/` preserves the original generated HTML README and its assets. The
maintained documentation starts at the repository-root README.
